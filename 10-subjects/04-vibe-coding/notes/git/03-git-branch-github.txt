1. 브랜치 (branch)
    1) main을 지키면서 따로 작업하는 공간
    2) 용도
        - main : 늘 실행되는 상태, 기준임
        - 기능마다 따로 브랜치 생성 
            - 실패한 시도는 그 브랜치만 삭제처리함
            - main에는 영향을 주지 않음
        - 여러 사람이 동시에 작업하는 경우
            - 각자 자기 브랜치에서 커밋하고, main에 합침.
        - main 브랜치에서 갈라져 나와 따로 작업하는 공간임
            - 작업 완료 후 main에 합침 (merge)

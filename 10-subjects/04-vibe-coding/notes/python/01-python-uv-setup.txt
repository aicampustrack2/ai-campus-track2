1. Python 환경구축하기 
    1) uv 설치
        - Python 설치, 가상환경, 패키지 관리를 하나로 처리하는 도구임.
        - powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
          - 공식 설치 스크립트 실행 
        - uv --version  
    2) uv로 Python 3.12 설치 
        - uv python install 3.12  
        - uv python list       # 3.12 줄 옆에 설치 경로가 보이면 성공

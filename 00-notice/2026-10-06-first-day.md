# 첫날 안내 — 수업 사이트 접속 등록과 로그인 방법

> 2026-10-06 · TRACK 02 개강

수업 슬라이드는 **https://ai-campus.pages.dev** 에서 봅니다.
이 사이트는 **등록된 이메일만 들어올 수 있도록** 이메일 인증으로 잠겨 있습니다.
그래서 첫날 각자 사용할 이메일을 등록하고, 그 이메일로 받은 인증번호로 로그인합니다.

---

## 전체 흐름

```
 ① 메일 보내기          ② 강사가 등록           ③ 사이트 접속
 ┌──────────────┐     ┌──────────────┐     ┌────────────────────┐
 │ 사용할 계정으로 │ ──▶ │ 접근 허용 목록에 │ ──▶ │ ai-campus.pages.dev │
 │ 강사에게 메일   │     │ 이메일 추가      │     │ 에서 이메일 입력      │
 └──────────────┘     └──────────────┘     └─────────┬──────────┘
                                                      ▼
                       ⑤ 로그인 완료            ④ 메일로 온 인증번호
                     ┌──────────────┐     ┌────────────────────┐
                     │ 수업 슬라이드   │ ◀── │ 사이트에 입력          │
                     │ 열람            │     │                      │
                     └──────────────┘     └────────────────────┘
```

---

## 1단계 — 강사에게 메일 보내기 (첫날 수업 중)

앞으로 6개월 동안 **수업 사이트에 쓸 메일 계정 1개**를 정합니다. 휴대폰에서도 바로 확인할 수 있는 계정이 좋습니다.
그 계정에서 아래처럼 메일을 보내 주세요.

| 항목 | 내용 |
| --- | --- |
| 받는 사람 | **aicampus.track2@gmail.com** |
| 제목 | **[TRACK02] 본인 이름** (예: `[TRACK02] 홍길동`) |
| 본문 | 비워도 됩니다 |

- **보낸 메일 주소가 그대로 등록됩니다.** 주소를 따로 적을 필요가 없어 오타가 생기지 않습니다.
- 그래서 반드시 **사이트에 쓸 그 계정에서** 보내 주세요. 다른 계정에서 보내면 그 계정이 등록됩니다.
- ⚠️ **이 저장소(이슈·댓글 포함)에는 이메일을 적지 마세요.** 공개 저장소라 누구나 볼 수 있습니다.

## 2단계 — 등록 완료 안내 기다리기

- 강사가 받은 메일의 보낸 주소를 사이트 접근 허용 목록에 등록합니다.
- **등록 완료 안내를 받은 뒤에** 3단계를 진행해 주세요. 등록 전에는 인증번호가 오지 않습니다.

## 3단계 — 로그인

1. 브라우저에서 **https://ai-campus.pages.dev** 에 접속합니다.
2. 로그인 화면에 **강사에게 메일을 보낸 그 주소**를 입력하고 인증번호 받기 버튼을 누릅니다.
3. 메일함에 온 **인증번호(숫자)** 를 확인합니다.
4. 사이트 화면에 인증번호를 입력하면 로그인됩니다.

- 인증번호는 **몇 분 안에만 유효**합니다. 시간이 지났으면 처음부터 다시 받으세요.
- 일정 시간이 지나거나 다른 기기·브라우저에서 접속하면 **다시 인증**해야 합니다. 같은 방법으로 로그인하면 됩니다.

---

## 인증번호가 오지 않을 때

| 확인할 것 | 해결 방법 |
| --- | --- |
| 스팸·프로모션 메일함 | 인증 메일이 스팸으로 분류되는 경우가 많습니다. 먼저 확인해 주세요. |
| 입력한 이메일 철자 | 강사에게 메일을 보낸 주소와 **한 글자라도 다르면** 인증번호가 오지 않습니다. |
| 등록 완료 여부 | 2단계 등록 완료 안내를 받았는지 확인해 주세요. |
| 위를 다 확인했는데도 안 될 때 | 강사에게 **이름만** 말씀해 주세요. 등록된 이메일을 확인해 드립니다. |

## 참고

- 수업 슬라이드는 **진도에 맞춰 차례로 열립니다.** 아직 열리지 않은 일차는 보이지 않을 수 있습니다.
- 실습 코드·가이드 같은 부가 자료는 이 저장소에 올라옵니다. 저장소 첫 화면의 「최신 공지」와 「현재 진도」를 수시로 확인해 주세요.
- 수업 일정과 진도는 상황에 따라 바뀔 수 있으며, 바뀌면 이 공지 폴더로 알려 드립니다.

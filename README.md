## ⏱ 자료 찾는 법 — 날짜가 아니라 주제로 찾습니다

과목 폴더는 날짜(일차)가 아니라 **자료의 종류와 주제**로 나뉘어 있습니다.
수업 일정이 앞당겨지거나 늦춰져도 자료의 위치는 바뀌지 않습니다.

```
 일정 (바뀔 수 있음)                       자료 위치 (바뀌지 않음)
┌──────────────────────────┐          ┌──────────────────────────────┐
│ 과목 README의 진도 표       │  링크 ─▶ │ labs/03-nat-gateway/  (실습)    │
│ 순서 · 주제 · 사이트 Day ·   │          │ files/               (예제 파일) │
│ 상태(예정·진행 중·완료)      │          │ references.md        (참고 링크) │
└──────────────────────────┘          └──────────────────────────────┘
```

- 실습 폴더 앞의 번호(`01-`, `02-` …)는 **배우는 순서**이지 날짜가 아닙니다.
- 한 실습이 이틀에 걸치거나 두 실습을 하루에 진행할 수도 있습니다.
- **오늘 어디를 하는지는** 위의 「현재 진도」와 각 과목 진도 표의 **진행 중** 표시로 확인해 주세요.
- 진도 표의 **사이트 Day**는 수업 사이트(ai-campus.pages.dev)의 Day 번호로, 같은 내용의 슬라이드를 찾을 때 씁니다.
- 일정이 바뀌면 [00-notice](./00-notice/)에 공지합니다.

## 자료 받기

처음 한 번만 내려받습니다.

```bash
git clone https://github.com/aicampustrack2/ai-campus-track2.git
cd ai-campus-track2
```

새 자료가 올라오면 아래 명령으로 최신 상태를 가져옵니다.

```bash
git pull
```

> 저장소 안의 파일을 직접 고치면 `git pull` 때 충돌이 날 수 있습니다.
> 실습은 저장소 밖으로 복사한 폴더에서 진행하는 것을 권장합니다.

## 주의 사항

- AWS 액세스 키, `.pem` 키 파일, `.env`, `terraform.tfstate`, kubeconfig 같은 **인증 정보는 절대 올리지 않습니다.**
  공개 저장소에 올라간 키는 몇 분 안에 자동 수집되어 악용될 수 있습니다. 이 파일들은 `.gitignore`로 막아 두었습니다.
- 이메일 주소·전화번호 같은 **개인정보도 이 저장소(이슈·댓글 포함)에 남기지 않습니다.** 공개 저장소라 누구나 볼 수 있습니다.
- 모델 가중치(`.gguf`, `.safetensors` 등) 같은 대용량 파일은 올리지 않고, 내려받는 방법만 안내합니다.
